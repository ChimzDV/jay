# Assets Folder — The Joyce Experience

This folder holds the visual and optional audio resources for **The Joyce Experience**:

- `companion-spirit.svg` — Nyx, the cute gothic anime-inspired floating spirit companion.
- `crest-moon-rose.svg` — The gothic crescent moon & dark rose emblem used in the Welcome Experience and headers.
- `wax-seal.svg` — The royal burgundy & gold monogrammed `"J"` wax seal on the Final Secret grimoire letter.
- *(Optional)* `ambient-theme.mp3` — The music toggle uses an atmospheric built-in Web Audio API dark-academia music box synthesizer out of the box (no external files required), or you can place an `ambient-theme.mp3` file here and reference it in `script.js` (`JOYCE_CONFIG.audio.customMp3Path`).
